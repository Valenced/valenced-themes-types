# Valenced Themes API types

Types for the [Themes API](https://github.com/Valenced/valenced-community-plugins/tree/main/plugins/api.themes) plugin.

Generated automatically. Do not edit this repository directly.

```sh
bun add -d @valenced/themes-api@git+https://github.com/Valenced/valenced-themes-types.git
```

Reference it so `api.themes` is typed, or add it to `compilerOptions.types` next to `@valenced/types`:

```ts
/// <reference types="@valenced/themes-api" />

import type { ThemeColors } from '@valenced/themes-api/types'
```
